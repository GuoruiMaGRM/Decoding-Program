# HHY 秩局部码译码实验：Linux / C++17 / NTL

本包只交付源码。交付前没有编译、运行正确性测试、运行译码实验或生成新的性能数据。代码尚未经过编译和运行验证。以下运行检查由脚本在你的 Linux 计算机上执行；检查失败时停止对应实例，不以替代算法的结果冒充该实例。

## 1. 这些实验究竟比较什么

主实验的对象是论文中的 HHY 环 Drinfeld 模所构造的秩局部码 C。不是码率为 1/N 的有限域乘法矩阵码，也不是交换子译码实验。

主比较固定同一个 C、同一个基域和扩域、同一组评价点、同一份接收向量、同一全局纠错半径。比较本文混合译码与下表八个算法。计时包含每个算法内部的候选生成、全坐标码字成员检验、全局错误秩检验和实际发生的回退。

| 程序名称 | 比较对象及其操作 | 使用的码 |
|---|---|---|
| `hybrid` | 本文方法：局部译码、局部残差形成错误值空间、缩短、子空间多项式变换、插值或变换后译码、全局验证与回退 | 同一个 HHY 码 C |
| `global_full` / GF | 在全部 n 个坐标上对包含 C 的 Gabidulin 码译码，再检验输出属于 C | 同一个 C；计算时使用包含码 Gab_KG(beta) |
| `global_screened` / GS | 先作 C 的成员筛查；否则在 KG+2*tau 个坐标上译码并在全部坐标验证 | 同一个 C |
| `rank_adaptive` / RA | 先尝试公开小半径 min(tau,max(1,u))，失败后全局译码 | 同一个 C；不读取真实错误秩 |
| `local_all` / LA | 逐块局部译码，验证拼接码字；失败后全局译码 | 同一个 C |
| `information_sets` / IS | 从预计算的信息集恢复候选并验证；失败后全局译码 | 同一个 C |
| `prefix_interpolation` / PI | 用 KG 个前缀坐标在包含的 Gabidulin 码中插值，验证后接受或回退 | 同一个 C |
| `multi_radius` / MR | 依次尝试公开的小半径 1,...,min(tau-1,3)，验证后接受或回退 | 同一个 C |
| `gao_cpp` | 本次独立编写的 Gao 形式译码：线性化插值、右欧几里得算法、左复合商和验证 | 同一个 C；计算时使用包含码 |

这里的包含码维数 KG 与实际消息维数 k 不同。GF、GS 和 Gao 是对 C 的通用全局译码方法，主实验没有把另一个码的接收向量交给它们。

`gao_cpp` 替换了旧实验中的 `sage_gao` 比较位置。它不是对 Sage 软件实现计时，也不是论文作者提供的优化实现。新旧两个程序的数值不能直接互换。其余全局、局部和变换后分量译码统一使用同一个 C++ 增量插值核心。独立的稠密 Welch–Berlekamp 方程组求解器仅用于计时外的正确性核对，不作为故意较慢的主基线。

还单独提供两类不同码的对照：

1. **多项式构造的秩局部码。** 恢复 E03 的四个参数配置，并增加三个与二进制 HHY 参数匹配的配置。评价空间采用 `z^i * F_(q^R)`，消息多项式采用分层的 Frobenius 单项式。全部九种译码方法在该码上再独立比较。它用于检查译码优势是否也出现在标准多项式构造上，不能用来证明 HHY 环构造独有的优势。旧 E03 的具体评价点未在现有完整论文包中给出，本包重新构造同参数的标准多项式实例，没有声称保留了旧 E03 的每个域元素。
2. **普通 Gabidulin 码。** 每个实例另测维数为 k 的同维数 Gabidulin 码，以及维数为 KG 的包含 Gabidulin 码。两者沿用同一个扩域、相同的 n 个评价点和相同的错误向量；各自发送独立随机码字。两种译码器均限制在公共半径 tau。结果写入独立的 `gabidulin_controls.csv`，不加入主实验的最快基线。维数 k 的 Gabidulin 码具有更大的最小距离，但没有本文保证的秩局部性；维数 KG 的包含码具有更高码率。这些差异不能省略。

## 3. Linux 一键运行

解压后进入目录：

```bash
cd HHY_CPP_NTL
bash run.sh
```

默认是正式采样配置：47 个配置、20 个独立种子、每个种子每种错误模型 16 个新输入、每个输入重复计时 3 次。全部译码、输入生成、域计算、统计、置信区间和 SVG 图像生成均为 C++。不需要 Sage、Python 或 Matplotlib。

缺少依赖时，脚本通过系统包管理器安装 C++17 编译器、GNU make、NTL、GMP 等；普通账户可能出现系统的 sudo 密码提示。不会下载或执行未知远程安装脚本。已有自定义 NTL 时使用：

```bash
NTL_PREFIX=/absolute/path/to/ntl INSTALL_DEPS=0 bash run.sh
```

只检查一个二进制实例及整条运行流程：

```bash
MODE=pilot SUITE=smoke bash run.sh
```

只做 E07–E09 的 16 个 q=7 配置：

```bash
SUITE=core bash run.sh
```

覆盖所有错误秩：

```bash
RANKS=all bash run.sh
```

补全 q=7 的低 s 趋势：

```bash
SUITE=extended bash run.sh
```

自选规模时不需要改 C++：

```bash
SEEDS='1001 1002 1003 1004' INPUTS=8 ROUNDS=2 RANKS='0;1;2;3' SUITE=core bash run.sh
```

`pilot` 的结果只用于排查流程。重复计时次数不增加独立输入数。默认全套含大量译码及独立正确性检查，不能将一个小测试的耗时当作全套运行时间。

中断后，以完全相同的参数指定原目录恢复：

```bash
RUN_DIR=/absolute/path/to/previous/results_directory bash run.sh
```

已完成的种子进程跳过；未完成的种子按确定性输入重新执行。源码、配置或二进制指纹变化时拒绝混合。`status.tsv` 保留失败和超时。C++ 单进程逐次计时，脚本不并行跑互相争抢 CPU 的基准进程；可用 `CPU=4` 指定一个允许使用的核心。脚本不锁定 CPU 频率。

## 4. 有限域、实例与参数

| 参数 | 明确含义 |
|---|---|
| q | 计算秩所用基域 F_q 的大小；本套包含 2、3、4、7 |
| M | 扩域 K=F_(q^M) 对 F_q 的次数；错误矩阵有 M 行 |
| ell、R、n | 块数、块长、总码长 n=ell*R |
| r | 包含局部码的 Gabidulin 维数 |
| b、s、k | 实际码维数 k=s*r+b，1<=b<=r，0<=s<ell |
| KG | 包含全局码的维数 s*R+b，不等于 k |
| u | 局部纠错半径 floor((R-r)/2) |
| tau | 共同的全局纠错半径 floor((n-KG)/2) |
| t | 生成器规定的真实错误秩，只用于生成及计时外检查，不传给译码函数 |
| a | 一次局部尝试观察到的错误值空间维数，在线计算 |
| MAX_SETS | 公开的最多块集合尝试数，默认 3，每组恰好 s 个块 |
| INFO_ATTEMPTS | 信息集基线的公开尝试上限，默认 7 |
| MAX_TRIAL_RADIUS | 多半径基线的公开小半径上限，默认 3 |
| source_M | HHY 模系数最初所在的小域 F_(q^source_M)，不是最终扩域次数 M |

对 q=p^a，程序在 NTL `zz_pE` 中表示 F_(p^(a*M))，显式嵌入 F_q，并构造其上的 M 维坐标基。因此 q=4 时度数为 2M，而错误秩按 F_4 计算，不能按 F_2 计算。运行检查明确验证 `{1,w}` 在 F_4 上的秩为 1，其中 w 是非素子域生成元。

五个二进制种子保留旧数据。`.code` 格式中另外保留原生成矩阵；加载时从消息多项式重新评价，逐项核对生成矩阵。

其他 HHY 配置在 C++ 内执行：度二 HHY 环模、辅助素理想与理想同源、商模、各有理素理想的挠点空间、逆同源评价点、消息空间的次数截断和局部 Gabidulin 包含检验。并非只生成一个满足相同参数的随机码。

C++ 与 Sage 的域模多项式和随机源不同，所以自动构造的实例不承诺与旧 Sage 实例逐元素相同。默认 `STRICT_M=1` 保持历史 M，按确定性的源选择顺序尝试至多 16 个合法源，逐个精确计算 Frobenius 周期。找不到兼容源时报告 `SOURCE_SELECTION_LIMIT`，不改 M，不换成多项式码，也不产生该配置的提速数据。可增加 `CONSTRUCTION_ATTEMPTS`。仅在明确研究更大扩域时才使用 `STRICT_M=0`；此时实际 M 写入快照和全部结果，该结果不再是原矩阵参数的复现。资源上限用 `MAX_M`、`PERIOD_CAP` 和超时变量控制，不解释为码不存在。

每次准备完成后保存完整 `.code` 快照，后续所有种子加载同一份域、评价点和码。域构造、码构造及固定码预计算的时间均在计时区外，并另行记录。不同算法的输入消息始终为随机消息，不固定为零码字。

## 5. 错误模型与理论对应

| 模型 | 生成规则 | 能支持什么结论 |
|---|---|---|
| `uniform_rank_t` | 随机独立的 t 个错误值作为基；系数矩阵在满行秩 t*n 矩阵中均匀抽样 | 固定秩条件下均匀错误，不指定不同 t 的发生概率 |
| `row_sparse_t` | 错误值空间由固定扩域坐标基中随机选择的 t 个方向生成 | 所选坐标基下的行稀疏模型 |
| `column_sparse_t` | 随机选择 t 个坐标，放入相互独立的非零错误值 | 恰有 t 个出错坐标，不能冒充一般秩 t 错误 |
| `first_block_t` / `last_block_t` | 只在第一块/最后一块产生秩 t 错误；t<=R | 测试块顺序和局部选择策略 |
| `crisscross_t` | floor(t/2) 个行方向加上其余列位置，按总秩恰为 t 接受 | 指定的混合几何；t=1 退化为单列错误 |
| `support_captured_t` | 生成时附加第一块覆盖完整错误值空间的条件 | 仅检验条件机制，单独标注，不当成无条件均匀错误 |
| `one_block_erasure` / `all_blocks_erasure` | 给出擦除位置；每个被测块擦去 R-r 个坐标 | 比较局部/全局线性恢复，不比较未知错误译码 |

每个输入在计时外记录各块真实错误秩、第一组块的局部正确条件、是否覆盖完整错误值空间。理论概率采用论文中的精确整数计数和动态递推，使用 NTL 大整数，不以独立块假设代替真实条件分布。`theory_exact_counts.tsv` 保存分子分母；`theory.csv` 保存概率。理论只针对一个固定的块集合及无条件 `uniform_rank_t`，不能套到条件捕获模型上，也不能把它直接当作 CPU 时间的预测。

运行检查核对以下对应：局部错误秩均不超过 u 时，本文算法不能全局回退；第一组局部正确且覆盖完整错误空间时，非零错误必须由插值分支返回；子空间多项式变换后的全局错误秩应为 t-a。理论事件和实验分支分别保留，罕见事件仍需足够样本，不能仅凭几个样本宣称概率吻合。

## 6. 消融实验

| 方法 | 改变的步骤 |
|---|---|
| `hybrid_no_interpolation` | 删除快速插值分支，保留错误空间变换和缩短译码 |
| `hybrid_no_projection` | 使用局部码字完成缩短，直接译码维数 b 的剩余 Gabidulin 问题，不使用错误空间变换 |
| `hybrid_one_set` | 只测试第一组 s 个块，保留全局回退 |
| `hybrid_no_fallback` | 删除全局回退，观察局部路径的成功率；失败允许，不能作为完整有界距离译码器 |

这些方法单独列出，不加入八基线的最小值。无回退方法发生失败时，不报告其“更快”的速度比。可用 `ABLATIONS=0` 关闭消融。

## 7. 输出和统计

运行结束会给出 `report/report.html` 的路径，可用浏览器打开。文件均由 C++ 产生：

- `report/summary.csv`：每个码与错误模型的本文均值、最快基线、时间比、配对种子置信区间及完整性标记。
- `report/methods.csv`：全部算法的均值、调用中位数、95% 分位数、独立种子数、不同输入数、成功率、回退率、分支比例和平均局部调用数。
- `report/ratios.csv`：各对照和消融的逐项时间比，消融有单独标记。
- `report/figures/*.svg`：每个实例的完整热图；未知错误与已知擦除分开成图。
- `workers/实例/seed_编号/模型.csv`：完整且已验证的模型原始计时；先写 `.partial`，完成后原子改名。汇总只读取完整模型文件。
- `raw.csv`：同一进程的便捷合并文件；中断时以完整模型文件为准。
- `inputs.txt`：接收向量、真实码字、错误向量和擦除位置，便于逐项复查；译码器不读取其中的真值。
- `gabidulin_controls.csv`：两个普通 Gabidulin 码的独立结果。
- `setup.txt`、`preparation/`、`environment.txt`：运行版本、预计算开销、构造记录和硬件信息。
- `status.tsv`：准备失败、验证失败、运行失败和超时均保留；失败不填为零耗时。

定义速度比为“八个基线各自平均时间的最小值 / 本文平均时间”。先对同一种子中的调用求均值，再对配对种子求均值，不使用逐输入比值的平均。绿底表示未舍入速度比大于 1；灰底表示不大于 1。颜色只描述观察到的均值关系。

置信区间按进程种子成组进行配对重抽样，每次都重新选择最快基线。重复计时不计作独立样本。少于 20 个种子或缺少请求种子的行标为 `incomplete_or_pilot`。即使区间在 1 上方，也只支持本机、本程序、该码与该错误模型的探索性比较，不等于普遍或渐近复杂度改进。

只重新汇总已有完整模型：

```bash
bash summarize.sh /absolute/path/to/results_directory 20
```
